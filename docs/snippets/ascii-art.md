# ASCII-арт и функции для fastfetch

Вывод команды `fastfetch`/`neofetch` можно украсить ASCII-артом. Лежит здесь, а не
в конфиге: это не настройка системы, а банк картинок.

## Функция для вывода

Удобно завернуть в функцию и вызывать из `~/.zshrc` или из алиаса. Пример, который
был в `docs/TODO.md`:

```bash
function ahegao() {
  echo "<строка 1>"
  echo "<строка 2>"
  # ... по одной echo на строку арта
}

alias myBuildSystem='sudo nixos-rebuild switch --flake ~/nixos-pc-conf && ahegao'
```

Вместо десятка `echo` можно проще — положить арт в файл и печатать его:

```bash
function ahegao() {
  cat ~/.config/ascii/nyan.txt
}
```

## Готовая картинка для fastfetch

`fastfetch --logo <path>` принимает путь к текстовому файлу или имя встроенного
логотипа (`fastfetch -l nixos_small`). Список встроенных:

```bash
fastfetch --list-logos
```
